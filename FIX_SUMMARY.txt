PROBLEM
-------
Your exit rules weren't firing because positions loaded from the broker had:
  1. max_loss = 0.0        -> STOP_LOSS rule broken
  2. max_profit = 0.0      -> PROFIT_TARGET rule broken
  3. delta = 0.0           -> P&L never updated
  4. entry_dte = 0.0       -> DTE_EMERGENCY couldn't fire

Result: Dynamic exit rules failed silently. Only time-based rules worked.

SOLUTION IMPLEMENTED
--------------------
Solution B: Fetch live option chain data for fresh P&L and Greeks

Changes to scripts/paper_trade.py (commit 684b0a3):

1. NEW FUNCTION: _compute_fresh_position_value(pos)
   - Fetches live options chain for each expiry in position
   - Looks up each leg strike to get fresh delta, bid, ask
   - Computes position-level delta (sum of legs)
   - Estimates position value from current option prices
   - Calculates fresh P&L: current_value - entry_value
   - Estimates max_loss/max_profit if zero (= premium * 1x/3x)

2. UPDATED: _run_exit_only()
   - Calls _compute_fresh_position_value() for each position
   - Uses fresh_pnl instead of delta-approximation
   - Updates position.delta with fresh market delta
   - Now exit rules have proper thresholds and current market data

IMPACT
------
Exit rules now fire correctly:

  STOP_LOSS:      P&L drops 75% of max_loss           [WORKS]
  PROFIT_TARGET:  P&L reaches 50% of max_profit       [WORKS]
  TRAILING_STOP:  P&L drops 10% from peak             [WORKS]
  DTE_EMERGENCY:  Approaching expiration (7/5 DTE)    [WORKS]
  HARD_EOD:       3:55 PM ET cutoff for intraday      [WORKS]
  FRIDAY_SWEEP:   Friday afternoon 2 PM closure       [WORKS]
  TIME_STOP:      Position age 21+ days (review only) [WORKS]
  REGIME_FLIP:    Market thesis invalidated           [WORKS]
